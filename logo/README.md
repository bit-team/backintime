That folder contain files related to the application logo of _Back In Time_.

- `backintime-qt.Source.svg` - The original file containing the logo and its
  symbolic version. All other logo related files are derived from that
  file. Modifications should be made on this file.
- `backintime-qt.svg` - The logo file used in _Back In Time_ GUI.
- `backintime-qt-symbolic.svg` - The symbolic version of the logo used in
  systray.
